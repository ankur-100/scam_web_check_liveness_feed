[Account Security] Is the Shopee OTP/verification code I received via WhatsApp genuine?

If you requested an OTP/verification code and it was sent to you via our official Shopee Security WhatsApp business account, it is genuine if the following features are present:

  1. The account name is "Shopee Security"
  2. There is a green check mark next to the name
  3. The WhatsApp account is a business account
